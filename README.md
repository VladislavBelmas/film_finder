# Film Finder

Консольное приложение для поиска фильмов в базе данных Sakila с интерактивным меню и пагинацией результатов.

## Описание

Film Finder — CLI-приложение на Python для работы с базой данных фильмов Sakila. Приложение позволяет искать фильмы по различным критериям, просматривать категории, а также анализировать статистику поисковых запросов.

### Функционал

- Поиск по названию — поиск фильмов по началу названия с фильтрацией по годам
- Поиск по году — поиск фильмов конкретного года выпуска
- Поиск по категории — фильтрация по жанрам
- Список категорий — просмотр всех доступных жанров
- Статистика — анализ поисковых запросов из MongoDB
- Пагинация — навигация по результатам (вперёд/назад)
- Логирование — запись запросов в MongoDB и app.log

## Требования

- Python 3.10 или выше
- Доступ к MySQL базе данных Sakila
- Доступ к MongoDB для логирования (опционально)

## Установка

1. Клонируйте репозиторий и перейдите в директорию:
```bash
git clone <url>
cd film_finder
```

2. Создайте и активируйте виртуальное окружение:

Windows:
```bash
python -m venv .venv
.venv\Scripts\activate
```

Linux/macOS:
```bash
python -m venv .venv
source .venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Настройка

Создайте файл `.env` в корне проекта:

```env
MYSQL_HOST=localhost
MYSQL_USER=root
MYSQL_PASSWORD=password
MYSQL_NAME=sakila

MONGO_URI=mongodb://localhost:27017/
MONGO_DB=film_finder_logs
MONGO_COLLECTION=queries
```

## Запуск

```bash
python main.py
```

## Использование

После запуска отображается главное меню:

```
 _________________________ 
|       FILM FINDER       |
|_________________________|
| 1. Поиск по названию    |
| 2.   Поиск по году      |
| 3. Поиск по категории   |
| 4.  Поиск по актеру     |
| 5. Показать категории   |
| 6.    Статистика        |
| 7.       Выход          |
|_________________________|
```

### Поиск по названию

Введите начало названия или оставьте пустым для всех фильмов. Укажите параметры в формате:
```
min_year max_year page limit
```

Пример: `2000 2010 1 10` — фильмы 2000-2010 гг., страница 1, 10 результатов на странице.

### Поиск по году

Укажите конкретный год выпуска и опционально начало названия. Параметры:
```
page limit
```

### Поиск по категории

Выберите категорию из списка по номеру или введите название. Затем укажите дополнительные фильтры по названию и годам.

### Статистика

Просмотр аналитики по всем поисковым запросам:
- Общее количество запросов
- Распределение по типам поиска
- Топ-10 самых популярных поисковых запросов

Статистика доступна только при подключении к MongoDB.

### Пагинация

При просмотре результатов:
- N — следующая страница
- P — предыдущая страница
- Q — вернуться в меню

## Логирование

Приложение ведёт два типа логов:

**Файл app.log** — операции с базой данных:
```
2026-06-04 23:00:00 - INFO - select работает штатно
```

**MongoDB** — поисковые запросы:
```json
{
  "query_type": "search_by_title",
  "parameters": {
    "title": "ACADEMY",
    "min_year": 2000,
    "max_year": 2010,
    "page": 1,
    "limit": 10
  },
  "result_count": 5,
  "timestamp": "2026-06-04T23:00:00.000000"
}
```

## Архитектура

Проект построен по слоям:

- **UI** (ui.py) — взаимодействие с пользователем, валидация ввода
- **Repository** (movie_repository.py) — бизнес-логика, логирование запросов
- **DB Clients** (mysql_client.py, mongo_client.py) — работа с базами данных через context managers
- **Config** (config.py) — параметры подключения из .env

## Безопасность

- Параметризованные SQL-запросы (защита от SQL Injection)
- Экранирование LIKE-спецсимволов (%, _, \)
- Валидация пользовательского ввода
- Ограничение limit (максимум 100 записей)
